Use the root Docker Compose files and README for the Linux-compatible development environment.

S3_ACCESS_KEY and S3_SECRET_KEY must be supplied through environment settings.
The optional CONFIG_PATH JSON file may contain configuration; environment variables override it.
Never commit credentials or use production data for tests.

Backend only (Java 17+ and Maven):
  mvn test
  mvn package dependency:copy-dependencies
  java -cp 'target/classes:target/dependency/*' org.mahat.Loader

PORT defaults to 12000. SESSION_SECURE defaults to true; set it to false for local HTTP only.

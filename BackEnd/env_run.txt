Use the root Docker Compose files and README for the Linux-compatible development environment.

Local Maven/VS Code runs read .env automatically and discover missing S3 credentials
from the MinIO/Silo container bound to the configured loopback port using Docker.
Existing configured credentials are preserved; discovered values are never printed or saved.
Production and remote storage require explicit S3_ACCESS_KEY and S3_SECRET_KEY settings.
Precedence: process environment > optional CONFIG_PATH JSON > nearest .env.
Never commit credentials or use production data for tests.

Backend only (Java 17+ and Maven):
  mvn test
  mvn compile exec:java

Packaged Java (production profile by default, requires configured credentials):
  mvn package dependency:copy-dependencies
  java -cp 'target/classes:target/dependency/*' org.mahat.Loader

PORT defaults to 12000. The local profile defaults SESSION_SECURE to false for local HTTP.
The production profile defaults SESSION_SECURE to true. CYPHERNOD_PROFILE can explicitly select either profile.
